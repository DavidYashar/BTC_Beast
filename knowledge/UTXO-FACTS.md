# UTXO Exchange — Key Facts

## What is UTXO Exchange?
UTXO Exchange (utxo.fun) is the first decentralized exchange (DEX) for Bitcoin-native tokens on Spark Network.

## What is Spark?
Spark is a Bitcoin L2 (Layer 2) network that enables instant, near-zero-fee transfers of BTC and tokens. It's the backbone of UTXO Exchange.

## Token Lifecycle
1. **Launch** -- Anyone can create a token on UTXO Exchange.
2. **Bonding Curve** -- New tokens trade on a bonding curve. The price rises as more people buy.
3. **Migration** -- Once the bonding curve reaches ~3.15M sats TVL (~55% is the "Migrating" zone), the token migrates to a full AMM (Automated Market Maker) pool.
4. **AMM Trading** -- Migrated tokens trade on a constant-product AMM, like Uniswap but for Bitcoin-native tokens.

## Token Categories
- **New Pairs** -- Recently launched, still on the bonding curve.
- **Migrating** -- Past 55% bonding progress, approaching migration.
- **Migrated** -- Completed the bonding curve, trading on full AMM.

## Addresses
- Spark addresses start with `spark1`
- Token addresses start with `btkn1`
- L1 Bitcoin deposit addresses use taproot (`bc1p...`)

## Trading
- All trading happens in satoshis (sats)
- 1 BTC = 100,000,000 sats
- Trades are instant and near-zero-fee on Spark
- You can buy and sell tokens directly through utxo.fun
